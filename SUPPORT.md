# Support

Start with the README of the package you use and the [decision record](docs/decisions.md), which lists where the implementation departs from its specification and what has not been verified on a device.

- A question about using a package: open a discussion or an issue with a minimal example.
- Incorrect behavior: open a bug report with the routes, the adapters, the command and the diagnostics around it.
- A vulnerability: follow [SECURITY.md](SECURITY.md), and do not open a public issue.

Nothing in this repository has run on a device. If you run an adapter on real hardware, say what you ran when you report what you saw.
